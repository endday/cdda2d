# 下一阶段任务表：把操作和物品系统补到「像 CDDA」

> 前置：等距渲染（45° 视角）已完成并上线。
> 下面五件事是现在和 CDDA 差距最大的地方，按依赖关系排。

## 顺序

```
T1 8 向移动 ──┐
              ├──→ T2 体力（消耗按距离算）
T3 装备位 ────┼──→ T5 物品动作菜单（wield/wear/吃/丢都在菜单里）
T4 体积重量 ──┘
```

建议 **T1 → T3 → T5 → T2 → T4**：

- T1 最便宜，做完手感立刻不一样；
- T3+T5 是「物品系统像不像 CDDA」的核心（现在伤害取"身上最好的东西"，很假）；
- T2 依赖 T1 的距离成本；
- T4 会连带改背包 UI，放最后一次性做。

---

## T1 · 8 向移动（斜走 141）

**现状**：只有 4 向，斜着走不了。

- 输入：方向键 + 小键盘 1–9 + `hjklyubn`（CDDA 键位）
- 成本：斜走 `int(100 * sqrt(2)) = 141` moves（CDDA 是 `move_cost * M_SQRT2`）
- 规则：**不能切角**——两个正交相邻格都堵住时，斜走也不许（CDDA 的 diagonal 检查）
- 怪物：`_steps_toward` 加斜向，否则追人永远走"楼梯"，看着很蠢

**改动**：`actions.gd`（Walk 费用/判定）、`world.gd`（切角）、`monster_brain.gd`、`main.gd`（键位）
**验收**：斜走扣 141；贴墙角斜走被挡；怪物能斜追；测试 +4
**估时**：2 小时

---

## T2 · 体力 stamina

**现状**：只有 moves，没有体力；走一百格也不喘。

- `Actor.stamina`（0–1000）+ `max_stamina`
- 每走一格扣 `moves * ratio / 100`：走路 ratio=1，跑步 ratio=10（CDDA 的 `PLAYER_BASE_STAMINA_BURN_RATE`）
- 跑步：移动模式开关（CDDA 用 `"` 键），每格只花 50 moves，但体力掉得快
- 喘气：体力低于阈值不能跑，且每回合回得慢
- 回合回复：站着回一点，跟饥饿/口渴挂钩
- UI：体力条（HUD 第三行）

**改动**：`actor.gd`、`world.gd`（回合回复）、`actions.gd`（跑步）、`main.gd`（UI/键位）
**验收**：连跑 10 格体力见底；见底后跑不动；不动会回；测试 +4
**估时**：4 小时

---

## T3 · wield / wear 装备位

**现状**：伤害取背包里数值最高的物品，护甲取最厚的——手上没拿也算数。

- `Actor.wielded: Item`、`Actor.worn: Array[Item]`
- 动作：Wield（100 moves）、Wear（100 moves）、Unwield
- 战斗：伤害只看 `wielded`，没拿就拳头；护甲只算 `worn`
- 背包面板：标出 `[手]` `[穿]`
- 存档 version 6

**改动**：`actor.gd`、`combat.gd`、`actions.gd`、`world.gd`（存档）、`main.gd`（UI）
**验收**：空手 3 / 拿刀 6；穿甲 3 / 不穿 0；读档后还在手上；测试 +5
**估时**：5 小时

---

## T4 · 体积 / 重量

**现状**：`weight`/`volume` 已经在 JSON 里，但没人读，背包无限大。

- `Actor.capacity_volume`（默认 2000 ml，背包 +2000）、`max_weight`（默认 20 kg）
- 拾取时检查：超了拒绝并说差多少（"再装 3.2L 装不下"）
- 负重：超重降速、加速体力消耗
- 背包面板：显示 `12.3 / 20 kg`、`1.8 / 4.0 L`，每件物品标重量

**改动**：`actor.gd`、`world.gd`（拾取/搬运）、`main.gd`（UI）、`items.json`（补齐数值）
**验收**：超重捡不起来；带背包容量变大；超重走路变慢；测试 +4
**估时**：4 小时

---

## T5 · 物品动作菜单（item_action）

**现状**：背包里按字母直接"用"，一件东西只能有一个动作。

- `content/item_actions.json`：动词表（eat / drink / wield / wear / apply / drop），带标签和条件
- `ItemActions.available(item, actor, world) -> [{id, label}]`
- 背包里按字母 → 弹出该物品的动作列表 → 再按字母执行
- 「用/吃/喝」仍然走现有的 `ItemUse` 注册表；`wield`/`wear`/`drop` 是新动作
- 数据驱动：新物品只要有 `use_methods` 或 `flags`，菜单里自动出现对应选项

**改动**：新增 `item_actions.gd`、`content/item_actions.json`；`main.gd`（二级菜单）
**验收**：水有「喝/丢」；刀有「手持/丢」；护甲有「穿/丢」；测试 +5
**估时**：5 小时
