# 下一阶段任务表：把操作和物品系统补到「像 CDDA」

> 前置：等距渲染（45° 视角）已完成并上线。
> 下面五件事是现在和 CDDA 差距最大的地方，按依赖关系排。

## 顺序

```
T1 连续移动 ──┐
              ├──→ T2 体力（消耗按距离算）
T3 装备位 ────┼──→ T5 物品动作菜单（wield/wear/吃/丢都在菜单里）
T4 体积重量 ──┘
```

建议 **T1 → T3 → T5 → T2 → T4**：

- T1 最便宜，做完手感立刻不一样；
- T3+T5 是「物品系统像不像 CDDA」的核心（现在伤害取"身上最好的东西"，很假）；
- T2 依赖 T1 的距离成本；
- T4 会连带改背包 UI，放最后一次性做。

## T1 · 连续移动与自动寻路 ✅ 已完成

**现状**：✅ 玩家坐标连续，鼠标点选目的地后沿路线自动移动；怪物继续使用地图单元行动。

- 输入：方向键自由移动；鼠标点击地面位置由 A* 找路并绕开障碍
- 成本：步行每地图单位 100 moves，跑步每地图单位 50 moves，按实际移动距离结算
- 规则：地图单元仍负责碰撞与寻路；路线预览标出本回合的预计停点

**改动**：`actions.gd`、`world.gd`、`monster_brain.gd`、`main.gd`
**验收**：✅ `tests/test_movement.gd` 覆盖距离成本、连续坐标、墙体阻挡、A* 绕行、存档兼容和怪物移动

## T2 · 体力 stamina

**现状**：只有 moves，没有体力；走一百格也不喘。

- `Actor.stamina`（0–1000）+ `max_stamina`
- 每走一格扣 `moves * ratio / 100`：走路 ratio=1，跑步 ratio=10（CDDA 的 `PLAYER_BASE_STAMINA_BURN_RATE`）
- 跑步：移动模式开关（CDDA 用 `"` 键），每格只花 50 moves，但体力掉得快
- 喘气：体力低于阈值不能跑，且每回合回得慢
- 回合回复：站着回一点，跟饥饿/口渴挂钩
- UI：体力条（HUD 第三行）

**改动**：`actor.gd`、`world.gd`（回合回复）、`actions.gd`（跑步）、`main.gd`（UI/键位）
**验收**：连跑 10 格体力见底；见底后跑不动；不动会回；测试 +4
**估时**：4 小时

## T3 · wield / wear 装备位 ✅ 已完成

**现状**：主手、副手、穿戴部位分开结算；主手优先攻击，主手空时副手武器可攻击。

- `Actor.wielded`、`Actor.offhand`、`Actor.worn` 独立保存
- 动作：主手、副手、穿戴、脱下，均消耗行动时间
- 战斗：主手优先，主手空时副手武器可攻击；护甲只算已穿戴物品
- 背包支持左键选中、右键动作菜单、拖拽物品到装备槽
- 存档记录主手、副手和穿戴部位

**改动**：`actor.gd`、`combat.gd`、`actions.gd`、`world.gd`（存档）、`main.gd`（UI）
**验收**：空手 3 / 拿刀 6；穿甲 3 / 不穿 0；读档后还在手上；测试 +5
**估时**：5 小时

## T4 · 体积 / 重量 ✅ 已完成

**现状**：拾取、负重速度和背包容积都按物品原型计算。

- `Actor.capacity_volume`（基础口袋 6 L，装备背包 +20 L）、`max_weight`（默认 20 kg）
- 拾取时检查：超了拒绝并说差多少（"再装 3.2L 装不下"）
- 负重：超重降速、加速体力消耗
- 背包面板显示负重和容积，每件物品标明占包空间；手持和穿戴不占容积

**改动**：`actor.gd`、`world.gd`（拾取/搬运）、`main.gd`（UI）、`items.json`（补齐数值）
**验收**：超重捡不起来；带背包容量变大；超重走路变慢；测试 +4
**估时**：4 小时

## T5 · 物品动作菜单（item_action） ✅ 已完成

**现状**：同一物品可由数据生成多个可用动作。

- `ItemActions.available` 从物品原型与 `use_methods` 生成可用动作
- `ItemActions.available(item, actor, world) -> [{id, label}]`
- 背包中左键查看动作列表，右键直接打开上下文菜单
- 「用/吃/喝」仍然走现有的 `ItemUse` 注册表；`wield`/`wear`/`drop` 是新动作
- 数据驱动：新物品只要有 `use_methods` 或 `flags`，菜单里自动出现对应选项

**改动**：`src/core/item_actions.gd`、`src/core/actions.gd`、`scenes/main.gd`（动作列表与右键菜单）
**验收**：水有「喝/丢」；刀有「手持/丢」；护甲有「穿/丢」；测试 +5
**估时**：5 小时
