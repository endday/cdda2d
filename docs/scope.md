# 第一版切片：一局 20~30 分钟

> 目标：不是“CDDA 的 Godot 版全部内容”，而是**CDDA-like 的骨架 + 一局能玩的内容**。
> 搜打撤后面当 `Scenario` 加；这一版先把“走/看/搜/吃/喝/打/做/存档”跑通。

## 1. 切片范围

| 项 | 最小版 | 不做什么 |
|---|---|---|
| 地图 | 48×32：一栋房子、一个商店、一个诊所、一条街、电台塔；FOV/雾 | 开放世界、多地图、载具 |
| 角色 | 1 人；100 HP；饥饿/口渴/感染；6×4 背包/20kg | 身体部位、温度、morale、技能树 |
| 回合 | 能量 100；走 100/打 100/搜 100/用 50/制作 300；敌人速度 50/100/150 | initiative、实时 |
| 物品 | 20 件：撬棍、刀、手枪、弹药、绷带、急救包、水、食物、净水片、火把、电池、开锁器、胶带、电线、电台零件、钥匙卡、护甲、背包、兴奋剂、抗生素 | 1000 件物品、CDDA 全表 |
| 配方 | 10 个：绷带、净水、火把、长矛、路障、开锁器、弹药、急救包、电台零件、背包 | 工作台等级/品质/拆解树 |
| 敌人 | 4 种：蹒跚、奔跑、吐酸、壮汉；简单 AI | 行为树、群体包抄 |
| 目标 | 修电台：找零件 + 找电池 + 到塔上修 + 守 10 回合 | “生存 N 天”无目标模式 |
| 死亡 | 永久死；结算：死因/存活回合/目标进度/带出物品 | 局外成长（第二版再说） |
| 存档 | 手动存档/读档；一局可存 | 云存档/多槽位（可后加） |

## 2. 一局的样子

1. 在街上醒来；附近有房子/商店/诊所。
2. 搜柜子：水、食物、绷带、撬棍、手枪、电台零件。
3. 撬门/砸窗进诊所；被蹒跚堵住；打或跑。
4. 口渴/饥饿见底；喝水/吃罐头；被感染；找抗生素。
5. 拿到零件 + 电池；去电台塔修；守 10 回合。
6. 死了 → 结算；活了 → 下一局/继续。

## 3. 自由度验收（8 件事）

同一局里，玩家能：

1. 撬门（撬棍）。
2. 砸窗（或开锁器）。
3. 做绷带（布/胶带）。
4. 喝水/吃罐头。
5. 搜柜子。
6. 打僵尸。
7. 感染 + 吃抗生素。
8. 睡觉/存档/读档。

**这 8 件事能发生，架构就成立；搜打撤只是再加一个场景。**

## 5. 验收

**J4 四问**（玩 3 局后写进 `first-battle.md`）：

1. 哪一刻想继续？
2. 哪一刻想关掉？
3. 哪个决定真的难做？
4. 看不看得懂？

**指标**：

- 一局 20~30 分钟。
- 能说出“我为什么死”（饥饿/口渴/感染/被打/走太深）。
- 想换一条路线/一套携带再来。
- 至少用了 2 个系统（生存/制作/战斗）。

## 6. 不做（第一版）

- 不做完整 CDDA；做“CDDA-like 骨架 + 一局内容”。
- 不做开放世界、多地图、载具、NPC 派系、基地建造。
- 不做 1000 件物品、身体部位、温度/疼痛/morale、技能树、联机、3D。
- 不做搜打撤（`Scenario` 是第二版）。

## 7. 这个底子够不够

**够开始，不够承诺“完整 CDDA”。**

- 6 个原语 + 20 件物品 + 3 条需求 + 10 个配方 + 4 种敌人 + 1 张图，
  足够做一局 20~30 分钟的切片。
- 架构能长大，但内容/模拟是长尾；完整 CDDA 是多年内容工程。
- 第一版必须是一局能玩的游戏，不是一堆框架。
